# ORDO Day / Month и selector — 8 октября 2026

## Итоговый scope

ORDO Month, ORDO Day, переходы между ними, отображение данных и отдельный
selector празднований / вариантов Литургии часов. Общие шапки, Liturgical
Picker и UX выбора даты после уточнения scope не перерабатывались. Слияние
веток не выполнялось.

## Что изменилось

Раньше основной ORDO Month был сеткой выбора даты, а ORDO Day повторял выбор
вариантов часов и предлагал много одинаковых переходов. Теперь это разные
компоненты с разными задачами:

- `OrdoMonthScreen` — вертикальный список всех дней месяца. Показывает
  основные празднования, альтернативы и commemoratio, литургические цвета,
  полезные ранги и диоцезальные подписи. Есть переходы между месяцами,
  выделение сегодняшней / выбранной даты, прокрутка к выбранной дате.
  Нажатие дня открывает существующий `/hours/ordo?date=…`.
- `OrdoScreen` — информационная страница дня с разделителями вместо карточек.
  Сохранены период, псалтырь, цикл, цвета, празднования, альтернативы,
  ссылки на чтения, доступные варианты часов, полезные указания и заметки.
  Подавленные празднования и общие заметки периода закрыты по умолчанию.
  Заметки конкретного дня доступны без раскрытия.
- Цветная сетка остаётся отдельным reusable компонентом выбора даты; ORDO
  Month её больше не использует.

На ORDO Day три основных действия: «Адкрыць чытанні», «Адкрыць Літургію
гадзін», «Ordo месяца». Нет кнопок для каждого чтения или варианта Office.
Одинаковые наборы ссылок на чтения объединяются; разные наборы сохраняются.
Обычные отрицательные флаги не выводятся как таблица. Правила первых/вторых
Нешпараў, особая Камплета, Te Deum и указания Тридуума сохранены.

## Selector

`showHoursOptionsSheet` открывает самостоятельный modal sheet. Название и
кнопка «Літургія» закреплены, содержимое прокручивается. Выбор применяется
сразу, нижняя кнопка закрывает selector. Используется UI sans-serif.

- 07.10.2026: «Найсв. Панны Марыі Ружанцовай», «Успамін», название один раз;
  нет radio для единственного празднования. Видны «З дня» и
  «Пра Найсвяцейшую Панну Марыю».
- 09.10.2026: будний день, св. Дионисий и св. Ян Леонарди — отдельные строки.
  Варианты часов появляются непосредственно под выбранным празднованием.
  Для Яна Леонарди проверены «З дня», «Пра пастыраў», «Пра справы
  міласэрнасці». Афиций за умерших вынесен в «ІНШЫЯ АФІЦЫІ».
- UI-ключи различают диоцезальные варианты одного празднования; выбор
  сохраняет контекст диоцеза и конкретную сборку Office.

`embedded` оставлен для совместимости с API параллельной работы. Сам selector
не содержит calendar grid. Самостоятельный вход — `showHoursOptionsSheet`.
После сужения scope обработчики общей шапки принадлежат параллельной работе:
в текущем `HomeScreen` они вызывают её `showLiturgicalCalendarSheet`, который
использует selector в режиме `embedded`. Этот обработчик больше не
переписывался. При объединении работ следует отдельно согласовать вызов
`showHoursOptionsSheet` из кнопки вариантов; готовый API не требует переделки
ORDO или engine. Самостоятельный modal selector и встроенный компонент
проверяются отдельно от UX выбора даты.

Литургический engine, `DayOption`, `DayTemplate`, разрешение чтений,
приоритеты и правила диоцезов не менялись.

Пересечения с общей навигацией / календарём, потенциальные merge conflicts:

- `lib/screens/home_screen.dart`: извлечение старого selector; в том же файле
  идут параллельные изменения общей шапки/даты и её обработчиков. Пробный
  прямой вызов standalone selector заменён параллельной работой; это точка
  согласования интеграции, а не изменение engine.
- `lib/widgets/app_shell.dart`: календарная кнопка Hours открывает ORDO Day
  с датой, выбранной сборкой и диоцезом.
- `lib/widgets/ordo/liturgical_month_calendar.dart`: ранняя замена serif
  заголовка на UI sans-serif; в рабочей папке также есть параллельный
  `didUpdateWidget`, который не относится к этой ORDO-задаче.
- `lib/widgets/hours_options_sheet.dart`: параметр `embedded` используется
  параллельным общим sheet, хотя самостоятельный selector отделён от сетки.

В рабочей папке также обнаружены параллельные изменения в
`liturgical_day_presentation_provider.dart`, `liturgical_day_header.dart`,
`liturgical_calendar_sheet.dart`, `liturgical_navigation_sync_provider.dart`,
`readings_screen.dart`, `ora_screen.dart`, темах reader/liturgical_document,
reader_scaffold, horizontal_swipe_navigation, pubspec.yaml/lock и их тестах. Они не являются
изменениями литургического engine этой задачи и не должны автоматически
попадать в отдельный ORDO commit.
