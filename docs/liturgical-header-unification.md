# Общая шапка литургического дня

## Границы

Общие шапки «Чытанні» и «Літургія гадзін» используют один выбранный день.
ORDO Month и ORDO Day остаются отдельным разделом. Шапка не открывает ORDO Day.
Существующий Liturgical Picker сохраняется как глубокий поиск по периодам и праздникам.

## Что исправлено

Раньше шапка чтений получала название и цвет из документа чтений. Для успаміна
документом по умолчанию могут быть будничные чтения, поэтому название и зелёный
акцент расходились с выбранным празднованием в часах. Теперь обе шапки используют
`liturgicalDayPresentationProvider`, построенный на существующем
`hoursLiturgicalSelectionProvider`. Цвет разрешает существующий
`liturgicalColorForDay` / `liturgicalVisual`; отдельного механизма цвета нет.

```text
Літургія гадзін / Чытанні
‹          7 кастрычніка 2026          ›
Найсв. Панны Марыі Ружанцовай
Серада · успамін
Іншыя літургічныя варыянты · N
```

Для буднего дня название — «XXVII звычайны тыдзень», метаданные —
«Аўторак · будні дзень». Подпись дня недели удаляется из конца названия,
но значимые названия воскресений и особых дней сохраняются.

Метаданные цикла и выбор набора чтений остаются отдельными. Переключение набора
чтений не меняет празднование, его название, цвет или выбранный афіцый.

## Календарный flow

```text
Дата в шапке → LiturgicalCalendarSheet
  ├─ существующий цветной LiturgicalMonthCalendar
  ├─ Сёння
  ├─ доступные празднования и варианты текстов выбранной даты
  └─ Знайсці літургічны дзень → существующий LiturgicalPickerScreen
```

Выбор даты сразу меняет общий контекст и список под сеткой. Выбор празднования
или варианта текстов также применяется сразу. Sheet остаётся открытым для
сравнения вариантов; «Гатова», крестик или закрытие жестом возвращают к разделу.
«Гатова» не является отдельным подтверждением выбора.

Ссылка «Іншыя літургічныя варыянты» открывает тот же sheet с первоначально
свёрнутой сеткой, чтобы варианты были видны сразу. Календарь можно развернуть.
Количество учитывает доступные варианты сборки текстов, включая варианты
одного празднования. Пустая секция вариантов не показывается.

WEB reference: `mybrev/src/components/common/CustomDatePicker.vue` получает
варианты из `pickerOptionsOf`; `OrdoDay.vue` отделяет празднования от чтений.
Во Flutter сохранены собственная сетка, ORDO service и объединение диоцезов.
WEB-разметка и отдельная система состояния не переносились.

## Компактный контрол даты (ноябрь 2026)

На обоих корневых экранах дата и стрелки живут в одной округлой панели
с тонкой обводкой. По нажатию на дату открывается прежний календарь.
Кнопка «Сёння» убрана из отдельной строки: когда выбран не сегодняшний
день, справа от даты появляется синяя кнопка с иконкой возврата (без текста).
Слот кнопки постоянно зарезервирован, поэтому дата не сдвигается при
переходе между сегодняшним и соседними днями. При уменьшении ширины и
увеличении шрифта дата переносится на несколько строк без удаления года.
ORDO и собственные кнопки даты внутри календаря не меняются.

## Навигация и совместимость

Стрелки и свайп используют `LiturgicalNavigationController.moveBy`, календарь
и «Сёння» — `openDate`, выбор варианта — `selectDay` того же контроллера.
`openDate` сохраняет ранее выбранный вариант при возврате к дате и проверяет
границы календаря. Выбор хранится в существующем session-scoped provider.

Свайп получил небольшое смещение за пальцем и плавный возврат. Существующий
переход между днями сохранён; PageView и повторная загрузка соседних дат не нужны.
При отключении анимаций системной настройкой переход выполняется без движения.

Пересечения с работой над ORDO:

- `lib/screens/home_screen.dart`: входы общей шапки принадлежат этому flow.
- `lib/widgets/app_shell.dart`: кнопка календаря в верхней панели открывает тот
  же calendar sheet, а не ORDO Day; навигация самого раздела ORDO не меняется.
- `lib/widgets/hours_options_sheet.dart`: существующий список переиспользован
  внутри календаря через `embedded`; самостоятельное окно сохранено.
- `lib/widgets/ordo/liturgical_month_calendar.dart`: минимальная совместимость —
  видимый месяц обновляется при внешней смене выбранной даты, включая «Сёння».
- `lib/providers/liturgical_navigation_sync_provider.dart`: общий API выбора
  даты/варианта; сигнатуры сохранены.
- `test/ordo_day_flow_test.dart`: минимальная адаптация входа — сценарии ORDO
  открывают его маршрут явно, поскольку кнопка шапки теперь открывает календарь.

Остальные изменения экранов ORDO и их тестов, присутствующие в общей рабочей
папке, не являются частью этой реализации шапок.
