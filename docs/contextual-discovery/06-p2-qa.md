## Как работает «не знаком» и «безопасная активность»
- Новое в состоянии движка: `visits` (счётчики по ключам `branch.prayerbook`, `branch.bible`, `section.songs`, `section.compendium`). Аддитивное поле, schema остаётся 1; старый payload без `visits` читается, битые значения → 0 (тесты). `historyReset` (QA-reset) очищает и счётчики.
- Счётчики пишут `AppShell` (смена ветки) и `DiscoveryVisitMark` вокруг `SongbookScreen`/`CompendiumScreen`. Без открытого Hive-бокса discovery — тихо ничего.
- P2 молчит, пока человек не сделал минимум 2 переключения вкладок дока в этой сессии (`discover.nav_switches ≥ 2`, память): подсказка не появляется сразу после запуска/onboarding.
- Квоты движка: один hint за визит, P2 — не чаще раза в 24 ч, максимум 2 показа на ID (`kP2MaxShows`), P0 > P1 > P2 (на корне Малітоўніка P1 «пошук» идёт первым), не при скролле/клавиатуре/модалке/переходе.
- Данные (песни, Кампендый, Библия) читаются только пока подсказка ещё может сработать; всё из бандла → работает offline. Ошибка/загрузка/пусто → факт `false` → no-op, кнопки нет.
