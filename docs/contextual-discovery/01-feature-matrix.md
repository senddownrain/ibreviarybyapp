## 2. Матрица ID

Условные обозначения статуса: **READY** — якорь, переход и источник подтверждены; **READY-cond** — подтверждено, но предикат требует счётчика/входа этапа 2; **DEFERRED** — подсказка выключена; **UNSUPPORTED** — недостающей функции нет, не придумывать.

Для **всех** ID общее правило подавления: `loading` / `error` / `unknown` (контент ещё не декодирован — `readingsLocalLoader` вернул `null`; `_error != null`; `_readings.isEmpty`), открытый modal/sheet/popup, клавиатура, активный скролл, смена даты в полёте, нет якоря на экране → **ничего не показывать**. Весь контент в бандле (`assets/content/*.json.gz`) — **офлайн: да** для каждой строки.

* Нет текста чтений: CD-X (2027-08-14 Гродзенская, 2027-07-02 Віцебская) → `ReadingsLoadResult(readings: [])` → экран «Чытанні для гэтага дня не знойдзены» → подсказки **не** показываются (`_readings.isEmpty`).
