## 6. Производительность
**Не измерялось.** Причины: профильный режим на симуляторе недоступен, debug-сборки (JIT, 90 МБ ядро) дают шум, который больше эффекта аналитики; A и B отличаются в debug на 8 байт ядра. Скорость запуска, p95 кадров, память и время сохранения `NOT MEASURED`; нужен профильный запуск на физическом iPhone. Ориентиры из других проверок: размер release APK +0,35 % (Android).
