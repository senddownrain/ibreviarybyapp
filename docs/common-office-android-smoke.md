Литургические сценарии, офлайн и замена старого APK проверены. Замечание
Android Back из первоначального прохода **исправлено и перепроверено**;
контракт и повторный навигационный smoke описаны в
[ora-back-navigation.md](ora-back-navigation.md). Ниже сохранён исходный

при этом проходе не изменялись. Merge, deploy и публикация не выполнялись.

## Устройство и установка

SDK, Emulator 36.4.10.0 и AVD Manager доступны; WHPX включён. Зарегистрированных
AVD не было. Создан ровно один новый `MyBrev_Test_API34`: профиль Pixel 7,
Android 14 / API 34 Google APIs, x86_64, RAM 4096 MB, 4 CPU, 1080×2400 / 420 dpi.
Старые AVD не восстанавливались. Дождались `sys.boot_completed=1`,
`dev.bootcomplete=1` и остановки boot animation. Android рендерился в эмуляторе
с `-no-window`; управление — ADB input, чтение — UIAutomator, снимки — screencap.

`flutter build apk --debug --no-pub` завершился успешно; APK установлен на
`emulator-5554`. Package: `by.mybrev.playtest2026`, versionName 1.0.0 / code 6.
SHA-256 текущего APK: `49b9fd2f8e97c7c695e9c8919a251ca31bf89db3a398601a01b55b87dda49633`.
Параметры, подпись и оба APK: [setup.json](../audit-evidence/common-office-android/setup.json).

На первом запуске Android были ANR Pixel Launcher/System UI при нехватке
памяти Windows. После остановки оставшихся от этой задачи Flutter Chrome
и Gradle daemon окружение восстановилось. Ошибок/ANR самого приложения
в сохранённых AndroidRuntime/flutter error log и process exit info не найдено.

## Первоначальное замечание навигации — исправлено повторным проходом

1. Открыть час из списка дня (например, Агульная гадзіна для religious).
2. Через «Змяніць гадзіну» выбрать Нешпары.
3. Нажать системный Android Back.

Фактически открывается Android Launcher вместо списка выбранного дня.
Common при переходе к Нешпарам сохраняется, аварийного завершения не обнаружено.
Контроль: Back из Ютрані, открытой непосредственно из списка, возвращает к дню.
Доказательства: `religious-vespers-switched-ui.xml`,
`back-after-hour-switch-ui.xml`. В первоначальном smoke исправление не
вносилось. Последующая правка и повторный native smoke закрыли этот дефект:
`audit-evidence/ora-back-navigation/`, три новых PNG и UI-дампы.
