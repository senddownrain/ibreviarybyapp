# PR #65: локальные права, документы на MyBrev Web

Текущее решение заменяет нативные статьи предыдущей версии PR #65. В приложение
включён только `assets/legal/sources.json`; полные декреты, календарный JSON/PDF,
их Dart-модели, экраны и два служебных маршрута удалены. WebView и офлайн-fallback
документов не добавляются.

Эталон прав — [Web PR #192](https://github.com/senddownrain/mybrev/pull/192),
commit `33577e1fb265b02160a5e6d94cfc83a8df15b9a3`. `sources.json` скопирован
побайтно. [web-import-lock.json](web-import-lock.json) фиксирует SHA-256 и источник.
Предыдущий эталон Web PR #189 / `f185657e88436eb8c6adb0f666b6e50bed416b40`
сохранён как исходная точка аудита реальных библейских корпусов.

## Библиография и происхождение

Все шесть ID сохранены: `bible-nt-kkbb-2017`, `bible-charniauski-2017`,
`bible-ru-synodal`, `lectionary-kkbb-2002-2005`, `liturgy-hours-2012-2020`,
`compendium-kkbb-2010`. В локальном JSON остаются переводы, цифровые источники,
выходные данные, evidence, нерешённые вопросы, метаданные декретов и история
атрибуции. Неустановленные сведения не дописаны.

- «Літургія гадзінаў» (Мінск, 2012–2020) — название в кавычках. Подпись прав:
  © Канферэнцыя Каталіцкіх Біскупаў Беларусі, без неподтверждённых годов ©.
- Кампендый публично показывает только © Канферэнцыя Каталіцкіх Біскупаў Беларусі,
  2010. LEV 2005 и путь исходного HTML сохранены в `auditNotices`, не в публичной
  подписи. Исходные метаданные самого корпуса Компендиума не редактировались.
- Уточнение правообладателя часов подтверждено в Web
  `docs/sources/primary/kremis-final-remarks-2026-11-06.md` как сведения задания
  владельца; оно не подменяет отдельное разрешение на цифровое использование.
- Подписи Библии и существующие цифровые ссылки footer читателей сохранены.
  Footer часов и Компендиума автоматически получает исправленные © из реестра.

## Внешние документы

Единственный файл URL — `lib/constants/legal_links.dart`, рядом с политикой
приватности. Базовый адрес: `https://ibreviaryby.web.app`.

| Подпись | Путь |
| --- | --- |
| Дэкрэты Літургіі гадзінаў | `/documents/liturgy-hours-decrees` |
| Агульныя ўводзіны да Літургіі гадзінаў | `/documents/liturgy-hours-introduction` |
| Уласны каляндар дыяцэзій на Беларусі | `/documents/proper-calendar` |

Каждая ссылка вызывает `url_launcher` с `LaunchMode.externalApplication`.
При `false` или исключении показывается:
«Не ўдалося адкрыць старонку. Праверце інтэрнэт-злучэнне».
Нативная копия документа не открывается. Успешный внешний запуск не меняет стек
Flutter; при возвращении из браузера остаётся страница источников.

AboutScreen сохраняет одну компактную ссылку. Герб, приход, разработчик,
приватность, версии и настройки не менялись. `/sources` остаётся служебным
маршрутом root navigator с прежним возвратом в About; четыре главные ветки и
их нижняя навигация сохранены. Нативных маршрутов отдельных документов больше нет.

## Блокирующая зависимость приёмки / выпуска

Перед merge и мобильным выпуском необходимо подтвердить публикацию **всех трёх**
URL на Web и открыть их из мобильного браузера без авторизации, особенно Уводзіны.
Web PR #192 слит 06.11.2026 в 12:56 UTC, merge commit
`d46d3a178e79bf73b62db56169bb555636aacf16`; его проверенный HEAD не изменился.
Merge не доказывает публикацию домена.

Прямой HTTPS-запрос к Уводзінам заблокирован управляемым прокси окружения:
`CONNECT tunnel failed, response 403`. Домен `ibreviaryby.web.app` отсутствует
в разрешённых адресах. Это отказ прокси, **не HTTP 403/404 самого сайта**;
опубликованность всех трёх страниц не установлена. Зависимость не снимается
локальным preview, наличием маршрутов в Web или тестом открытия вкладки.

PR #65 оставлен **draft, без merge**. Мобильная публикация запрещена до выполнения
этой сквозной проверки. Web merge/deploy в рамках Flutter-задачи не выполняются.

Unit/widget проверки охватывают шесть записей, точную библиографию, права часов,
отсутствие LEV в публичных подписях, сохранённое происхождение, три HTTPS URL,
внешний режим запуска, оба вида ошибки, Back и отсутствие полнотекстовых assets
в реальном Flutter AssetManifest. Регрессии включают Библию, footer Чтений/часов,
Компендиум и архитектуру навигации.

Chrome smoke использует production SourcesScreen/router и реальные локальные
права, без Firebase и записи пользовательских предпочтений. Нормальные ссылки
открывают отдельные браузерные вкладки через настоящий `url_launcher_web`.
Запросы содержимого документов намеренно прерываются тестом: это проверка
внешнего запуска, а не опубликованного Web. Отказ браузера воспроизводится
изолированным provider override только в harness.

Результаты и несколько актуальных снимков: `audit-evidence/source-documents/`.
Исходная база проверок сохранена отдельно в `baseline-checks.json`.
Android/iOS устройства недоступны; проверки TargetPlatform и Chrome не заменяют
native smoke внешнего браузера/системного возврата перед релизом.
