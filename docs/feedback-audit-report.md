# Flutter: аудит обратной связи (2026-11-13)

Полная матрица точек входа (Web + Flutter, PASS/FAIL), состояния формы и результаты тестов — в `docs/feedback-audit-report.md` репозитория `senddownrain/mybrev` (PR «Feedback audit»). Здесь — Flutter-часть.

## Что изменено
* Пункт «Памылка» в меню ⋯ следует **видимой** странице, в том числе открытой через `context.push` (`ImperativeRouteMatch`). Без этого на Гадзінах, открытых из списка, пункта не было (дефект найден на iOS Simulator).
* Новые точки входа: Ordo (день `/hours/ordo?date=…`); Катэхізіс уже ведёт в Кампендый.
* Типы часов Flutter (`laudes`, `lectionis`, `terz/sext/non`, `completorium`, `invitatorium`, `vespers`) приведены к допустимым значениям контекста.
* Контекст: читаемая подпись («Малітва · Ойча наш», «Літургія гадзінаў · 2026-11-13 · Ютрань»), диоцез читателя (`minsk-mohilev` → `minsk_mohilev`, как требует Worker).
* `requestId` теперь на сообщение, а не на экран: идентичный повтор — тот же id, после правки текста — новый; `409 request_id_reused` обрабатывается один повтор с новым id.
* Форма: компактный чип контекста, равные по высоте горизонтально прокручиваемые чипсы, категория «Іншае» по умолчанию без контекста, баннер «Няма сеткі» (connectivity), экран успеха с копированием номера, «Вярнуцца да чытання» и «Напісаць яшчэ».
