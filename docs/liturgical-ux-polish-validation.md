# Финальная полировка литургического UX

## Реализация

- Общая шапка: день недели 18 px / semibold, вторичные сведения 14,5 px; книжные названия и растущая вертикальная лента сохранены.
- Читатель: центральное название часа и chevron без отдельной чёрной подложки; общая нейтральная защита верхнего chrome, область нажатия от 48 dp, перенос длинного названия при системном масштабировании.
- При дополнительном пересмотре верхней панели уточнён расчёт ширины текста после ограничения селектора до 340 dp; высота общей подложки соответствует переносу на широких экранах. Скруглена только подсветка нажатия, постоянной капсулы нет. `reader_foundation_test.dart` повторно прошёл 10/10 с ширинами 320/800 dp, Android/iOS, двумя темами и TextScaler 1/2 (`build/polish-reader-reviewed.log`).
- Hours и Readings: дата открывает тот же селектор с развёрнутым календарём, «Іншыя варыянты» — со свёрнутым. Маркеры святкований справа, radio слева.
- Readings: переключение святкования, группы, комплекта, года и даты не закрывает панель. `ValueListenableBuilder` обновляет её по изменению существующего состояния; временный notifier содержит только номер обновления. Списки пересчитываются, несовместимый ручной цикл сбрасывается, допустимые выборы сохраняются. Закрытие — через «Гатова», X, Back или жест.
- Календарь внутри раскрываемой панели: отдельный `PageStorageKey` горизонтальной прокрутки исключает конфликт `double`/`bool` с состоянием `ExpansionTile`.
- ORDO: только календарная сетка при нажатии даты, обновление текущей страницы; общий `dioceseSelectionProvider`, сохранение в тех же настройках, минимум одна диоцезия. Временный контекст ссылки не изменяет настройки и уступает последующему явному изменению выбранных диоцезий.
- ORDO Day: основное святкование сразу после даты/дня недели/диоцезий; лента растёт вместе с названием, рангом и метаданными; короткие переходы «Літургія» и «Чытанні»; ссылки под соответствующими святкованиями с устранением повторов; книги, источники и рубрики сохранены ниже.
- Повторное открытие того же маршрута ORDO с новой датой/источником обрабатывается в `didUpdateWidget`. Это исправление выявлено при проверке Android.
- ORDO Month: тот же общий выбор диоцезий; небольшие цветовые маркеры перенесены вправо.

## Android

Android 14 / API 34, отдельный Pixel 7 (`Pixel7_API34_Audit`, `emulator-5654`), аппаратный рендеринг, 720×1600 при density 280 — тот же размер интерфейса в dp; трёхкнопочная системная навигация.

Первый integration-прогон реально установил APK, открыл MainActivity, отрисовал интерфейс и прошёл: `build/polish-native-first.log`. Просмотрены чистые кадры Hours/Readings, вариантов, диоцезий/настроек, ORDO Month, длинного названия Терезы, прокрученного Закліку, конца часа, рождественских комплектов и системного масштаба 200%.

Первые кадры первого прогона перекрывали системные ANR-диалоги при нехватке памяти. Они не использовались как подтверждение чистого интерфейса. После освобождения памяти и закрытия системных диалогов проверка продолжилась нормально.

Финальный повторный integration-прогон обновлённой версии прошёл за 11:56, exit 0 (`build/polish-native-final.log`). Дополнительно проверены новый маршрут ORDO, переход через «Далей» и длинное название часа при системном тексте 200%. Кадры удерживались по 8 секунд для надёжного захвата. Просмотрены чистые кадры обеих тем, открытых селекторов и календарей, диоцезальных различий 26.08.2026, правых маркеров ORDO Month, прокрученного часа и его конца; системный масштаб после проверки восстановлен до 100%.

Последняя композиционная правка ленты ORDO и повторно пересмотренная верхняя панель проверены дополнительно в обычном приложении из финального APK, без integration test. Использован отдельный AVD `Pixel7_LiturgicalFinal`, `emulator-5654`. Запуск через `flutter run --no-pub --use-application-binary ../native-polish/app-latest.apk` записан в `build/polish-normal-reviewed.log`. При нехватке RAM повторялись ANR System UI и process system; первая программная отрисовка не дала чистого экрана и не засчитана как успешная визуальная проверка. После освобождения памяти и перезапуска только этого AVD с `-gpu host -memory 1536` приложение реально отрисовало интерфейс. Потребовались повторный запуск Activity и снятие блокировки экрана. Другие задачи и их эмуляторы не останавливались, сообщения им не отправлялись.

Фактически просмотрены финальные кадры: главная Hours (`normal-host-awake.png`), прокрученный Заклік (`normal-final-hour-top.png`), открытый переключатель часов (`normal-final-hour-picker.png`), «Малітва перад поўднем» при системном масштабе 200% (`normal-final-hour-large.png`), открытые настройки Aa (`normal-final-hour-aa.png`), ORDO 10.10 с окончательной лентой (`normal-final-ordo-ribbon.png`), календарная сетка ORDO (`normal-final-ordo-date.png`) и длинное название Терезы 01.10 с растущей лентой при масштабе 200% (`normal-final-ordo-large-title.png`).
