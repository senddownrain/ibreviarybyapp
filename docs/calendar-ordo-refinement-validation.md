# Календарь, дата и ORDO — 12 октября 2026

Работа выполнена на `main`, исходный HEAD `94fbc08`. Существующие параллельные изменения доступа священников, content bundle, Firebase и инструментов публикации сохранены.

## Изменения

- `LiturgicalCalendarDisclosure` — одна компактная строка для селекторов Hours и Readings: подпись слева, chevron справа, минимум 48 dp, одинаковые шрифт, цвет, отступы и анимация 200 мс. При reduce motion анимация выключена. Иконка календаря не дублируется. Состоянием владеет конкретный selector; изменение даты/святкавання не сбрасывает пользовательское раскрытие. Дата открывает календарь сразу, «Іншыя варыянты» — свёрнутым. Compact calendar ORDO сохранён.
- `LiturgicalDateNavigationRow` используется общей шапкой Hours/Readings и ORDO: System UI 18/600, нейтральный ink, центральная дата, выровненные стрелки и области нажатия 48 dp. При крупном тексте строка растёт. Контекст, weekday, Today, пределы календаря и обработчики остаются специализированными.
- ORDO: родитель `_Section` рисует единственную тонкую линию; все основные и вложенные раскрытия используют `_DetailDisclosure` с пустыми `shape`/`collapsedShape` и локальным прозрачным dividerColor. Раскрытие не добавляет линий. Заголовки секций единообразны, содержимое имеет общий внутренний отступ. Состояния сохраняются при закрытии и повторном открытии секции.
- «Літургія гадзінаў»: отдельные сведения «Афіцый» и «Псалтыр»; список формуляров только при нескольких вариантах, текущий обозначен «Абрана». Одинаковое с верхней кнопкой «Літургія» действие удалено из содержимого. Единственный вариант не показывается как список выбора. Разделение источников Mass/Office сохранено.
- «Асаблівыя ўказанні»: небольшая типизированная презентационная модель `_OrdoFact` содержит label, value, context и badges. Она формируется непосредственно из разрешённого дня: Нешпары, Камплета, Te Deum, первые Нешпары и правила первенства. Данные всех выбранных диоцезий объединяются только при совпадении значений и контекста. Различия имеют подпись диоцезии. На широком экране — две колонки, на узком и при крупном тексте — вертикальная композиция.
- «Літургічныя заўвагі»: только непустые тематические группы, компактные muted заголовки, полный текст Literata 16/1.5, источник отдельной подписью. Варианты заметок всех выбранных диоцезий сохраняются. Большой массив периода и подавленные празднования остаются второстепенными раскрытиями. Загрузка и ошибка имеют явный статус; основные данные дня остаются доступны.
- «Літургічныя кнігі»: название и том получены из `OrdoBooks` отдельно, совпадения объединены по диоцезиям; раздел свёрнут. Значения и наличие книг не выдумываются. Для 04.04.2026 в имеющихся данных тома не заданы; книги проверяются на 11.10.2026.

## Воспроизведение native-снимков

В одном терминале:

```powershell
python test_driver/quiet_book_native_capture.py audit-evidence/calendar-ordo-refinement
```

В другом:

```powershell
flutter drive --no-pub -d emulator-5654 --driver=test_driver/quiet_book_driver.dart --target=integration_test/calendar_ordo_refinement_test.dart
```

Захват через adb включает системные панели. Скрипт временно устанавливает системный текст 200% и восстанавливает исходное значение. Flutter surface conversion не используется.

Адресные проверки и анализ описаны выше. Полный набор и итоговый Android UI на
этом снимке не подтверждены; результаты локальных снимков остаются в
`audit-evidence/calendar-ordo-refinement/`.
