# Налады V1 в Chrome

Снимки сделаны в Google Chrome из Flutter Web. Сценарий открывает production `SettingsScreen` и существующие экраны обратной связи и информации. Офлайн-обновления и особлівы доступ используют локальные фикстуры. Настройки темы и переключателей хранятся в отдельном локальном Hive-профиле браузера.

```powershell
flutter devices
flutter run -d chrome --profile --no-web-resources-cdn -t tool/settings_smoke.dart --web-port 5239 --web-hostname localhost
```

Открывать `http://localhost:5239/`. Для масштаба 150% и 200% использовать `http://localhost:5239/?scale=1.5#/settings` и `http://localhost:5239/?scale=2#/settings`. Ширина выставляется через эмуляцию viewport Chrome DevTools. Масштаб относится к системному тексту интерфейса. Значение «Памер тэксту» на эталонах соответствует 100% читательского шрифта.

## Состояния и переходы

- [Свёрнутый «Тэкст»](390-text-collapsed.png) скрывает оба примера, псалмодыю и цветовое выделение.
- Переходы ведут на [«Зваротная сувязь»](390-feedback.png) и [«Інфармацыя»](390-about.png). Форма проверялась без отправки.
- Ссылка `section=sync` прокручивает до [«Дадзеныя афлайн»](390-offline-link.png). Совместимая ссылка `section=data` использует тот же переход.
- Перезагрузка вкладки сохраняет явный выбор «Не гасіць экран». Нативную работу удержания экрана нужно проверить на устройстве перед следующим мобильным релизом.
