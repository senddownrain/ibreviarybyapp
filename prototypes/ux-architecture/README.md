# iBreviary: изолированный UX-прототип

Интерактивная браузерная модель по `docs/ibreviary-ux-handoff.md` от 08.09.2026. Весь код находится в этой папке; production Flutter UI, Firebase, Hive и MyBrev не изменяются. Не требует npm install, Flutter или доступа к сети.

Запуск из корня репозитория:

```powershell
node prototypes/ux-architecture/serve.mjs
```

Открыть http://127.0.0.1:4178. Сервер слушает только localhost. Для другого порта используйте переменную `UX_PROTOTYPE_PORT`. Можно также открыть `index.html` напрямую: ресурсы локальные, запросов к API нет. Сервер удобнее для стабильного хранения состояния браузером.

На широком экране показаны обе платформы, на узком выбирается одна через «Платформа». Light/dark и масштаб системного текста 100–200% находятся за пределами модели приложения. Сценарии слева/сверху сбрасывают **только демонстрационное состояние** обоих телефонов к нужному примеру. Обычные четыре tabs внутри телефона ничего не сбрасывают.

## Реализованные маршруты

| Вход | Действие и результат |
| --- | --- |
| Гадзіны | Дата → празднование → заметные alternatives → список всех восьми часов. Один tap на час открывает Ora. |
| Alternatives | Меняют празднование и контекст Ora. Первый элемент подготовленного массива — primary. Недоступный вариант виден, но не выбирается. При одном варианте действие скрыто. |
| Дата | Sheet: Today, предыдущий, следующий, календарь, поиск литургического дня/праздника. Быстрые действия закрывают sheet. На другой дате отдельная кнопка «Сёння». |
| Ora → Чытанні | Явное действие переносит дату Ora. Выбирается default набора чтений этой даты. Выбранное празднование Ora не используется как неявная связь. Back возвращает дату, вариант, час и его scroll offset. |
| Чытанні | Сразу евангельский текст; выбор празднования и применимых I/II или A/B/C вторичен. Ручной выбор подписан; есть возврат к автоматическому. |
| Малітоўнік | Все шесть демонстрационных Абраных непосредственно списком, затем «Мае зборнікі», категории и все молитвы. Текст открывается одним tap. |
| Prayer detail | Полный текст выбранной молитвы/песни из источника, избранное, настройки чтения, Back. |
| Поиск молитв | В верхнем chrome. Поле сразу получает фокус. Название/текст, фильтры, пересечение с открытым сборником. Возврат из найденной молитвы восстанавливает запрос и фильтр. |
| Біблія | Сразу последнее место, перевод, выбор книги/главы, предыдущая/следующая глава, поиск названий книг и текста **текущей книги**, отметки стихов. |
| Меню | Settings, About, Sync; выбор стартового раздела, включая «Апошні адкрыты». |
| Reader chrome | Полные tabs по умолчанию. В iOS явная демонстрация минимизации в Aa. В Android нет scroll auto-hide. На обеих платформах явный focus mode с постоянно доступным выходом. |

## Границы данных и правил

- «Сегодня» намеренно зафиксировано на **2026-09-08** для повторяемого ревью; доступные calendar fixtures: 8, 9 и 13 сентября. После полуночи текст не подменяется. Другие даты открывают явное отсутствие набора. Это не полный календарь.
- Порядок вариантов — подготовленный fixture-массив, интерпретируемый как уже отсортированный результат `LiturgicalContentService`. Новый precedence resolver не создавался. Не утверждается нормативная правильность демонстрационного списка.
- Production default readings не изменяются. Модель использует подготовленные группы, первый default, только доступные циклы и календарную формулу из `liturgical_cycle.dart`; отсутствующий ожидаемый цикл возвращает первый доступный. Полный `ParsedReadingsService.fetchForDate`, календарные группы и fallback на реальном Hive здесь не исполняются. Их интеграционная проверка остаётся этапом Flutter.
- Readings показывает реальный библейский евангельский отрывок в **демонстрационном наборе**, а не полный набор чтений Мессы. Это подписано под текстом. Ora — сокращённый образец с общими и собственными частями, не полностью собранный афиций; также подписано в reader.
- Bible: шесть полных книг — Мц, Мк, Лк, Ян, Пс, Рым — со всеми главами в двух переводах из `assets/bible_seed_{bel,ru}.json.gz`. При экспорте нормализованы различающиеся ID (`ru jo` = Иоанн, `ru jn` = Иона; `bel rom` = Римлянам). Сохранены исходные номера и текст стихов.
- Ora и тексты молитв/песней: константы `lib/screens/ora_screen.dart`; публичные файлы `mybrev/patchs/db-feasts/08-09-nativity-blessed-virgin-mary.json` и `09-09-sv-peter-claver--pastors.json` из указанного UX-референса. Никакие приватные backups или пользовательские коллекции не экспортировались.
- Абраныя, названия сборников и их состав демонстрационные. Их изменения, позиции, выбранные переводы и настройки сохраняются только в `localStorage` с префиксом `ibreviary-ux-prototype-v1:` отдельно для iOS/Android. Доступ к настоящим пользовательским данным отсутствует.
- Статусы загрузки и синхронизации переключаются вручную. «Паўтарыць» моделирует успешное восстановление, не вызывает сервер. Offline с доступным содержимым не сопровождается постоянным banner.

`fixtures.js` уже включён: соседний MyBrev нужен только при повторном запуске `extract-fixtures.py`, не для использования прототипа. Экспорт читает только перечисленные публичные источники.

## Визуальная адаптация

Использованы принятые цвета и интервалы из `docs/design/mobile-design-tokens.json`: mist-indigo ambient в свободном пространстве, непрозрачный reader, локальные литургические маркеры. Обычный текст не обёрнут в GlassSurface или вложенные cards.

iOS использует браузерную имитацию полупрозрачного chrome. Это **не системный Liquid Glass**. Android — непрозрачные tonal surfaces, крупные мягкие формы и отдельные floating controls. Chrome остаётся доступным при обычном скролле. «Паменшыць эфекты» отключает ambient/blur; системный reduced motion учитывается CSS.

Геометрия safe area здесь моделируется внутри рамки телефона. Настоящие iOS/Android safe areas, экранная клавиатура, VoiceOver/TalkBack, нативное выделение, системные жесты и frame timings требуют проверки на устройствах. Браузерная проверка их не заменяет. Picker использует browser date input внутри адаптированного sheet, а не настоящий Cupertino wheel/Material calendar.

## Проверка

```powershell
node --check prototypes/ux-architecture/app.js
node --test prototypes/ux-architecture/model.test.cjs
```

Автоматически проверяются перенос даты/возврат Ora, независимость tabs и scroll keys, сброс ручного выбора при новой дате, empty day, циклы около Advent, сохранение порядка избранного и целостность текстов обоих переводов. Результаты браузерного прогона и ограничения — в `QA.md`.

Для ревью ключевого перехода откройте сценарий **04 Ora → Чытанні**: Ora относится к 9 сентября и святому Петру Клявэру. Действие «Чытанні» открывает 9 сентября, default обычного дня, цикл II. Верхняя стрелка «Да Ora» возвращает выбранную Ютрань святого Петра. Переключение обычным tab сохраняет независимую дату каждой ветки.
